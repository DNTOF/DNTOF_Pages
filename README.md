# DNTOF_Pages

个人主页，使用 Anthropic 风格设计。

🔗 [在线访问](https://dntof.com)

## 功能

- **个人介绍** — 姓名、身份、简介、技术标签
- **重点项目** — SLDataAPI 特色展示区
- **项目列表** — 所有 GitHub 项目卡片
- **外部链接** — GitHub、爱发电

## 设计

采用 [Anthropic](https://www.anthropic.com) 官方品牌风格：

- 暖米色大地调（`#ECE9E0`）底色
- Poppins + Lora 字体混排
- 克制的橙色（`#D97757`）作为强调色
- 大留白 + 叙事感排版
- 自动适配深色模式
- 移动端响应式

## 技术栈

- HTML5 + CSS3（纯静态，无框架依赖）
- Google Fonts（Poppins / Lora / LXGW WenKai / Noto Sans SC）

## 部署

通过 GitHub Pages 部署于 `dntof.com`，无构建步骤，推送即生效。
